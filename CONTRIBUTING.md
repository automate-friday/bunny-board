# Contributing to Bunny Board

This repository publishes reviewed releases of Bunny Board. Development happens in a
separate private repository. Release commits contain the source snapshot and its file
manifest, without private development history.

## Reports and ideas

Open an issue with the problem, expected behavior, steps to reproduce, environment and
sanitized screenshots or logs. Please remove credentials, private conversations and
personal information. Explain what you need to accomplish; a small reproduction helps.

Public pull requests are proposals and reference material. We do not merge them into
this repository or automatically import their patches. Maintainers may use the reported
problem, reproduction or design as inspiration for an independent implementation in the
private source. That implementation goes through our tests and release review before a
new source snapshot is published. A proposal may be closed without a code merge.

We credit useful reports and ideas in release notes where appropriate. Submitting a
proposal does not guarantee implementation or a release date. This policy is intended
to keep one maintained source and a clear release boundary.

## Security reports

Do not post live credentials or private captures in public issues. Use the support
contact in [the self-hosted guide](docs/self-hosted.md) for sensitive reports.

## Installing

Start at [the README](README.md). Installation requirements and third-party licences
still apply; this contribution policy does not grant a new software licence.
